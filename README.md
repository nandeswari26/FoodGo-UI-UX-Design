# 🍔 FoodGo – Food Delivery App UI/UX Design

This project is a mobile UI/UX design for a food delivery application created using Figma.

## 📱 Screens Included
- Sign Up
- Login
- Home
- Restaurant List
- Cart
- Checkout
- Order Confirmation

## 🎨 Tools Used
- Figma
- Iconify Plugin
- Google Fonts

## ✨ Features
- Clean UI
- User-friendly navigation
- Prototype linking
- Auto layout
- Scrollable screens
